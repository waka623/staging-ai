# 編集一式（生成したクリップ → 60秒の完成動画）

## フォルダ
| 場所 | 中身 |
|---|---|
| `clips/` | 生成したクリップを `C01.mp4`〜`C13.mp4` の名前で置く（カット番号は `../01_shotlist.md` と同じ） |
| `audio/` | `bgm.mp3`（明るいBGM）、`child_laugh.mp3`（子どもの笑い声）、`pico.wav`（通知音） |
| `timeline.json` | 各カットの長さ・頭上の数字・テロップ・色・音の配置。**調整はここだけ書き換える** |
| `build.py` | timeline.json のとおりに書き出すスクリプト |
| `make_placeholders.py` | 動作確認用の仮素材を `placeholder/` に作る |
| `fonts/` | Noto Sans JP（SIL Open Font License。`LICENSE_FONT` を参照） |
| `out/` | 書き出し結果（`reel.mp4`）と確認用の静止画 |

## 使い方
```bash
python3 build.py --stills
```
- `out/reel.mp4`（1080×1920・30fps・H.264/AAC・60秒）と、1秒ごとの静止画（`out/stills/`）ができる
- 一部のカットだけ直したときは `python3 build.py --only C05` で、そのカットだけ作り直せる
- 素材が無いカットは黒い画面、無い音は省いて書き出す（途中経過の確認用）

## timeline.json の主な項目
- `color.saturation`：作品全体の時間に対する鮮やかさ（1.25＝鮮やか、0＝白黒）。初期値は0〜20秒が鮮やか、40秒までにグレー
- `color_mask`：そのカットで、指定した円の中だけ色を戻す（40〜55秒の「子どもの周りだけ自然な色」）。`cx`・`cy` は画面に対する割合
- `badges`：頭上の数字。`x`・`y` は画面に対する割合、`values` は `[秒, 値]` の組で、値は数字が増える動きで補間される。ほかに `blink`（赤く点滅）、`shake`（揺れ）、`confetti`（紙吹雪）、`scale`・`alpha`（大きさ・透明度の変化）、`path`（位置の移動）、`crowd`（群衆の数字をまとめてランダムに配置）を指定できる
- `captions`：テロップ（`\n` で改行）
- `audio`：`at` 秒に音を置く。`af` に ffmpeg の音声フィルターを書くと音を加工できる（35〜40秒の歪み）。最後に全体の音量を -14 LUFS にそろえる

## 注意
- 数字の位置は人物の動きを自動では追いかけない。実際のクリップを見て `x`・`y` か `path` を合わせる
- C13（視聴者の頭上に数字が出るカット）の映像はまだ決まっていない
- BGMを10〜20秒でテンポアップさせる処理は入れていない。曲自体に盛り上がりがあるものを選ぶか、別の曲に切り替える
