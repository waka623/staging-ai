# Google Vids 用プロンプト：60秒の完全版

これまでの決定事項（主人公・場所・C06/C13の変更・10秒以降の服装）をすべて反映した、1回で60秒全体を指示するためのプロンプト。

```
縦型9:16、合計ちょうど60秒、13シーンのショートドラマ動画を作ってください。
セリフ・ナレーションは入れず、映像・音・短いテロップだけで伝えます。
実写風（シネマティック、35mmフィルム風、浅い被写界深度）で、全シーンの画質と色味をそろえてください。

【テーマ】もしも、他人の評価が頭の上に数字で見えたら
【メッセージ】その行動は、自分のためか、他人の目のためか
【視聴者】ショート動画をよく見る大学生

【主人公】20歳の日本人の男子大学生。細身、明るく人当たりのいい顔、明るい茶髪のセンターパート、眼鏡なし。全シーンで必ず同じ人物にしてください。
・0〜5秒の服装：グレーの無地スウェット、ベージュのチノパン、白スニーカー、無地の黒いトートバッグ
・5秒以降の服装（シーン3で着替えたあと最後まで）：白シャツにクリーム色のニットベスト、ワイドスラックス、白スニーカー、無地の黒いトートバッグ

【舞台】秋の東京、都心の現代的な大学キャンパス（ガラス張りの校舎、紅葉）。0〜40秒は昼の自然光、40秒以降は夕方の暖かい光。

【物語の流れ】周りの目に合わせるほど評価は上がるが、だんだん自分を見失う（0〜40秒）。数字のない子どもと出会い、素の自分に戻る（40〜55秒）。最後に視聴者へ問いかける（55〜60秒）。

【シーン】
1（0-3秒）：主人公がキャンパスの広場を歩くと、周りの学生が一斉に振り向く。ゆっくり寄るカメラ。テロップ「もしも、他人の評価が見えたら。」
2（3-5秒）：俯瞰で、学生が行き交う広場全体。
3（5-10秒）：全身鏡の前で、韓国風のレイヤードコーデに着替え、鏡を見て満足そうに笑う。
4（10-15秒）：キャンパスで友人の輪の中、主人公は少し遅れて周りに合わせて笑う。作り笑い。
5（15-20秒）：おしゃれなカフェで、ラテアートをスマホで角度を変えながら何度も撮る。
6（20-25秒）：ベンチで、自分が踊っている動画を投稿しかけるが、近くの学生の視線を気にして迷い、下書きのまま削除する。
7（25-30秒）：トイレの鏡に映った主人公の顔だけがぼやけている。静かな場面。
8（30-35秒）：下から見上げる構図。周りの学生が無表情で主人公を見下ろし、主人公は小さく見える。
9（35-40秒）：主人公が自分の頭の上の空中を両手で必死に振り払う。手持ちカメラで揺れる。
10（40-45秒）：夕方の小さな公園。5歳くらいの子どもが泥遊びをして、無邪気に笑っている。
11（45-50秒）：泥だらけのボールが転がってきて、主人公が思わず受け取る。手が泥で汚れる。
12（50-55秒）：主人公がボールを持ったまま、素の笑顔になる（顔のアップ、夕日）。
13（55-60秒）：スマホを見ている学生（主人公とは別の人）を正面から撮る。画面の向こうの視聴者に見立てる。最後にゆっくりカメラの方を見上げる。テロップ「その数字、誰のため？」

【音】
0〜10秒：明るいBGMと通知音「ピコン」
10〜20秒：BGMがテンポアップし、「ピコン」が連打される
20〜35秒：BGMがだんだん暗くなる
35〜40秒：BGMが歪む
40〜55秒：BGMを止め、子どもの笑い声だけ
55〜60秒：最後に「ピコン」1回で終わる

【文字について】
・テロップはシーン1とシーン13の2つだけ。白い太字、中央寄せ
・映像の中に文字・数字・ロゴ・看板を描かないでください（頭上の数字は後から編集で重ねます）
```

## 補足
- 頭上の数字・色の変化（鮮やか→グレー→子どもの周りだけ色）は、`GoogleVids_プロンプト.md` の「③ 編集で足すもの」を見て編集で重ねる
- シーンごとの作り直しには、`GoogleVids_プロンプト_10秒以降.md` の英語プロンプト（シーン4〜13）と、`GoogleVids_プロンプト.md` の②（シーン1〜3）を使う
